# TokenDusk

TokenDusk enables multi-modal data processing for decentralized applications, utilizing analytics and autonomous decision-making within a self-sustaining network system.

TokenDusk is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/TokenDusk.git`
2. `cd TokenDusk`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure TokenDusk, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
